## 🛠 Tech Stack

* **Backend:**
  * **Python / Django** — core business logic framework, data processing, and report generation.
  * **Django ORM** — automated database migrations for rapid iterative prototyping.
  * **Celery + Redis** — background tasks, asynchronous event processing, scheduled reminders, and parcel analytics.
  * **Django Channels + WebSockets** — real-time bidirectional communication for live notifications and dashboard updates.
* **Server & Deployment:**
  * **Uvicorn** — WSGI/ASGI server for multi-threaded and multi-process request handling.
  * **Docker & Docker Compose** — containerization of the entire stack (app, database, message broker).
* **Database:**
  * **PostgreSQL** — primary relational database for operational data and transaction history.
* **Frontend & Templates:**
  * **Django Templates** — server-side page rendering.
  * **Vue.js (Composition API via CDN)** — lightweight reactivity, interactive filters, dynamic tables, and widgets embedded directly into Django templates without heavy build steps.

* **Сервер та контейнеризація (Server & Deployment):**
  * **Uvicorn** — WSGI/ASGI-сервер для багатопотокової та багатопроцесної обробки запитів.

* **База даних (Database):**
  * **PostgreSQL** — основне реляційне сховище для управлінських даних та історії операцій.

  * **Django Templates** — серверний рендеринг сторінок.
